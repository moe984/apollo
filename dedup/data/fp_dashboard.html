What is Hash Dedup?

When a security alert arrives, the system creates a fingerprint by hashing four fields together: source IP, destination IPs, alert rule name, and a 30-minute time bucket. If two alerts produce the same hash within the same time window, the system treats them as the same incident — the first alert gets investigated, and the second is silently suppressed.

This works when the hash has strong, unique data. It fails when key fields are missing. If both IPs are empty, the hash collapses to just the rule name and time bucket, causing unrelated alerts to look identical and get grouped together.
